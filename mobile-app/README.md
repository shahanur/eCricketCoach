# eCricketCoach - Native Mobile Apps

This directory is reserved for future native/cross-platform mobile applications (React Native / Flutter / iOS & Android) for eCricketCoach.

## Target Capabilities
- Offline sync for pitch-side video recording and coach reviews.
- High frame-rate slow-motion camera integration (120/240 fps) for cricket action capture.
- Biometric & on-device pose estimation preprocessing.
- Push notifications for training plan updates and assessment reviews.

The mobile apps will consume the containerized REST API provided by the `web-app/server` service.
